# Ecommerce Customer Analysis (Linear Regression)

This project is a guided machine learning project completed as part of my learning journey. The goal is to analyze e-commerce customer data and understand what factors influence yearly customer spending.

## 📊 Dataset
The dataset contains customer information such as:
* **Average Session Length:** Average session of in-store style advice sessions.
* **Time on App:** Average time spent on the mobile app in minutes.
* **Time on Website:** Average time spent on the website in minutes.
* **Length of Membership:** How many years the customer has been a member.
* **Yearly Amount Spent:** The target variable we are predicting.

## 🛠️ Tools & Libraries Used
* **Python** (Core language)
* **Pandas & NumPy** (Data manipulation)
* **Matplotlib & Seaborn** (Data visualization)
* **Scikit-learn** (Linear Regression model & Evaluation)

## 🚀 Project Workflow
1. **Data loading and inspection:** Checking for missing values and data types.
2. **Exploratory Data Analysis (EDA):** Using Seaborn to find correlations between features.
3. **Model Building:** Splitting data into Training and Testing sets.
4. **Model Evaluation:** Calculating MAE, MSE, and RMSE to check accuracy.

## 💡 Learning Outcome
Through this project, I understood the end-to-end machine learning workflow and how linear regression is applied to real-world-style data. I am currently working towards building my own independent projects using new datasets.
